# TWICHT-plugin

Widgets et overlays pour les streams Twitch.

## Projets

| Dossier | Description |
|---|---|
| [`g4p-cap-sur-le-tresor/`](g4p-cap-sur-le-tresor/) | Objectif de dons Streamlabs pour Gamers4Pets 2026 (Team Chien, thème pirate) : un navire qui avance vers l'île au trésor. |
| [`g4p-carte-au-tresor/`](g4p-carte-au-tresor/) | Jeu de nuit pour Gamers4Pets 2026 : le chat vote pour creuser une carte au trésor pendant que Burri dort, les dons creusent plus vite, les gages découverts sont à faire au réveil. |
| [`barre-dons-g4p/`](barre-dons-g4p/) | Barre d'objectifs de dons Streamlabs Charity pour Gamers4Pets 2026 (Team Chat, thème pirate) : paliers, km à marcher, bandeau « Palier débloqué » et plan B sans Streamlabs. |
